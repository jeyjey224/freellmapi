Beleg fotografieren oder hochladen
Bilder (JPG, PNG, HEIC*) oder PDF, auch mehrere gleichzeitig. Oder hierher ziehen.

Die Texterkennung läuft direkt in deinem Browser (Tesseract OCR, Deutsch). Betrag, Datum, Händler und Kategorie werden automatisch erkannt, du kannst alles vor dem Speichern korrigieren. Für bessere Ergebnisse kannst du unter Einstellungen eine KI (z. B. deinen FreeLLMAPI-Server) aktivieren.
*HEIC nur in Browsern, die es anzeigen können (z. B. Safari).

KI-Erkennung (optional)

Statt nur OCR kann ein Vision-Modell über eine OpenAI-kompatible API den Beleg lesen, etwa dein lokaler FreeLLMAPI-Server (http://localhost:3001/v1 mit deinem Unified Key). Das Bild wird dafür an diesen Endpoint gesendet. Schlägt die KI fehl, wird automatisch OCR verwendet.

Daten

Alle Belege werden nur lokal in diesem Browser gespeichert (IndexedDB). Mach regelmäßig ein Backup.
